# Курсовая: дифференциальная геометрия и основы тензорного исчисления

## Материалы

- [`теория.md`](./теория.md) — полный конспект с формулами для чтения на GitHub.
- [`теория.pdf`](./теория.pdf) — тот же текст с оглавлением и оформлением для печати.

## Две части конспекта

| Часть | Содержание |
|---|---|
| I · Разделы 1–8 | Векторные пространства, базис, координаты, линейные отображения, ковекторы и двойственное пространство |
| II · Разделы 9–16 | Билинейные формы, метрический тензор, тензоры, метрика на многообразии, связность Леви-Чивиты, кривизна и полный расчёт для сферы |

Обозначения и правила суммирования общие для обеих частей. Продолжение начинается с билинейных форм и доводит дорожную карту до единичной сферы $S^2$.

## Что читать

Читать книги целиком не нужно. База для этой курсовой:

1. **М. М. Постников — «Лекции по геометрии. Семестр V. Риманова геометрия»**  
   Основное: римановы и псевдоримановы пространства; связность; кривизна; локально симметрические пространства; пространства постоянной кривизны.  
   https://publ.lib.ru/ARCHIVES/P/POSTNIKOV_Mihail_Mihaylovich_%28matematik%29/

2. **Barrett O'Neill — _Semi-Riemannian Geometry with Applications to Relativity_**  
   Только разделы: Tensors; Semi-Riemannian Manifolds; Special Relativity; Symmetry and Constant Curvature.  
   https://shop.elsevier.com/books/semi-riemannian-geometry-with-applications-to-relativity/oneill/978-0-12-526740-3

3. **Л. Д. Ландау, Е. М. Лифшиц — «Теория поля», т. 2**  
   Только начало: принцип относительности; интервал; собственное время; преобразования Лоренца.  
   https://www.sciencedirect.com/book/monograph/9780080250724/the-classical-theory-of-fields

### Если проседает линейная алгебра

**MIT 18.06 Linear Algebra** — Vector Spaces, Basis and Dimension, Linear Transformations.  
https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/

## Текущий маршрут теории

Векторное пространство → линейные комбинации и независимость → базис → координаты → линейные отображения → двойственное пространство → билинейные формы → метрический тензор → метрика → связность → кривизна → сфера.

## Обновление PDF

Нужны Python 3, Pandoc, XeLaTeX и шрифты DejaVu / Latin Modern Math. Из корня репозитория:

```bash
python3 scripts/build.py
```

PDF собирается из `теория.md`; настройки оформления находятся в `config/`. Многострочные формулы записаны блоками `math`, которые GitHub отображает без конфликта с заголовками Markdown.

Для Obsidian можно получить копию с обычными блоками `$$`:

```bash
python3 scripts/build.py --obsidian теория-Obsidian.md
```
