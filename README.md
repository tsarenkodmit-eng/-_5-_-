## Сборка PDF

Нужны Python 3 с ReportLab, Pandoc, XeLaTeX, шрифты DejaVu и Latin Modern Math.

```bash
python3 -m pip install reportlab
python3 scripts/build.py
```

Команда создаёт **пять отдельных PDF теории и один PDF условия**. Части не объединяются. Сборка одной части:

```bash
python3 scripts/build.py --part 5
```

Для повторной сборки только условия:

```bash
python3 scripts/build-assignment.py
```

Экспорт одной части для Obsidian с обычными математическими разделителями:

```bash
python3 scripts/build.py --part 4 --obsidian /tmp/theory-04-Obsidian.md
```

Исходные формулы используют блоки `math` и защищённые встроенные выражения для GitHub. Настройки печати — в `config/`; старый адрес `теория.md` сохранён как указатель.
