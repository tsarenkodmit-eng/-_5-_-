# Курсовая по дифференциальной геометрии · вариант №9

**[Открыть итоговую курсовую — solution.pdf](./solution.pdf)**

Единый итоговый документ содержит теоретический пункт о псевдоевклидовом пространстве и его связи со специальной теорией относительности, необходимые определения римановой геометрии и полное решение задачи о сфере. Вычисления приведены последовательно: от параметризации и метрики до связности, тензора кривизны, Риччи, гауссовой и скалярной кривизн. Локальная симметричность доказана через ковариантную постоянность тензора кривизны; приведена короткая геометрическая проверка.

Для сферы радиуса a получены K = 1/a² и Scal = 2/a². Для стандартной единичной S²: K = 1, Scal = 2; сфера с обычной метрикой локально симметрична.

Содержание заново сопоставлено с подробной инструкцией по каждому обязательному пункту. Отдельно выполнены независимые математический и смысловой проходы; все страницы итогового PDF просмотрены после сборки. Основу составляют фактически использованные книги Постникова (семестры II и V) и Ландау—Лифшица, указанные в самом документе и в [карте источников](./sources.md).

**Окончательный результат и последующие дополнения публикуются под одним именем `solution.pdf`.**

Доступная постановка: [текст варианта](./assignment-09.md) · [цифровой PDF задания](./assignment-09.pdf). Редактируемый [исходный текст курсовой](./coursework-09.md) сохранён отдельно от итогового документа.
