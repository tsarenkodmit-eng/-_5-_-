## Сборка PDF

Нужны Python 3, Pandoc, XeLaTeX и шрифты DejaVu / Latin Modern Math. Из корня репозитория:

```bash
python3 scripts/build.py
```

Команда обновляет три отдельных PDF. Для одной части:

```bash
python3 scripts/build.py --part 3
```

Экспорт одной части для Obsidian с обычными блоками `$$`:

```bash
python3 scripts/build.py --part 3 --obsidian /tmp/theory-03-Obsidian.md
```

Исходные формулы оформлены блоками `math` и защищёнными встроенными выражениями для отображения на GitHub. Настройки печати — в `config/`. Старый адрес `теория.md` сохранён как указатель на части.
