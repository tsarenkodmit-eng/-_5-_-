## Что читать

Читать книги целиком не нужно. База для этой курсовой:

1. **М. М. Постников — «Лекции по геометрии. Семестр V. Риманова геометрия»**  
   Основное: римановы и псевдоримановы пространства; связность; кривизна; локально симметрические пространства; пространства постоянной кривизны.  
   https://publ.lib.ru/ARCHIVES/P/POSTNIKOV_Mihail_Mihaylovich_%28matematik%29/

2. **Barrett O'Neill — _Semi-Riemannian Geometry with Applications to Relativity_**  
   Только разделы: Tensors; Semi-Riemannian Manifolds; Special Relativity; Symmetry and Constant Curvature.  
   https://shop.elsevier.com/books/semi-riemannian-geometry-with-applications-to-relativity/oneill/978-0-12-526740-3

3. **Л. Д. Ландау, Е. М. Лифшиц — «Теория поля», т. 2**  
   Только начало: принцип относительности; интервал; собственное время; преобразования Лоренца.  
   https://www.sciencedirect.com/book/monograph/9780080250724/the-classical-theory-of-fields

### Если проседает линейная алгебра

**MIT 18.06 Linear Algebra** — Vector Spaces, Basis and Dimension, Linear Transformations.  
https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/

\to g

$$
